# Домен трассировки алгоритмических структур (Control Flow Statements)

Данный домен предоставляет тренажер для развития у студентов навыка понимания того, как программа выполняется пошагово. В упражнениях студенту предоставляются задачи с базовыми алгоритмическими структурами (таких как, следование, циклы, ветвления) в поддерживаемых языках программирования

С 2025 года, домен переходит на использование [модели деревьев мыслительных процессов](/docs/decision_tree/). Домен по-прежнему продолжает использование автоматизированной генерации задачи из открытых проектов, однако с поддержкой преобразования фрагментов кода с помощью [Meaning Tree](/docs/meaning_tree/)

## Принцип работы домена

*Основная статья: [Принципы построения домена CtrlFlow](./Принципы модели домена)*

1. Генератор задач получает очередной фрагмент исходного кода из реального проекта и преобразует его в представление [Meaning Tree]
2. Генератор задач создает формализованное представление задачи на конкретном языке программирования, которое готово для [рассуждателя](/docs/decision_tree/2.%20Вычисления%20(its_Reasoner)/Об its_Reasoner) и HTML код задачи с интерактивными кнопками
3. CompPrehension при запуске упражнения с применением этого домена отрисовывает для пользователя условие задачи
4. При нажатии кнопки, домен формирует трассу выбранных действий из сформированных данных задачи и отправляет в рассуждатель дерева
5. После получения результата от дерева мыслительных процессов, домен интерпретирует обратную связь для студента от дерева

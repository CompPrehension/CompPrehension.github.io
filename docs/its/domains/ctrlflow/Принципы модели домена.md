# Модель предметной области домена трассировки алгоритмических структур

> [!warning] Данная страница находится в процессе написания

Основная идея представления задачи данного домена заключается в представлении фрагмента исходного кода в виде графа потока выполнения программы **(Control Flow Graph, далее CFG)**, по которому рассуждатель может определить, правильно ли студент понимает порядок выполнения программы

Кроме графа, для задачи и, в частности, для языка программирования, должны быть сформированы готовые правила о том, как должно осуществляться формирование графа и прохождение по нему. Для удобства рассуждения, эта логика может "вшиваться" прямо в условие задачи наряду с отдельной декларацией.

## Базовые концепции

Дерево описывается в LOQI формате

### Control Flow Graph, CFG

Граф потока выполнения программы, состоит из узлов (вершин) и дуг. Всегда имеет точку входа (начальный узел) и узел выхода (конечный узел). 
Для задач домена важно, чтобы в CFG был маршрут от начального до конечного узла

![Пример CFG](/images/domains/cfg_example.png)

### Узел графа

Поля:

- `id` - идентификационная строка, уникальное имя узла
- `role` - ???
- `kind` - один из типов узла

#### Типы узлов
- `BEGIN` - начало какого-то действия
- `END` - завершение какого-то действия
- `ATOM` - атомарная инструкция (не требующая завершения, например: простой statement или выражение условия в цикле/ветвлении)

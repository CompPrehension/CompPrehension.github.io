**thought-process-graph** - навык (agent skill) для LLM-агентов, описывающий, как работать с графами мыслительных процессов, языком LOQI и проектами `its_DomainModel`, `its_Reasoner` и `its_QuestionGen`.

Репозиторий: [github.com/CompPrehension/thought-process-graph-skill](https://github.com/CompPrehension/thought-process-graph-skill)

Навык представляет собой набор инструкций в формате [Agent Skills](https://code.claude.com/docs/en/skills): корневой файл `SKILL.md` с кратким описанием и рабочим процессом, а также несколько справочников в `references/`, которые агент подгружает **только тогда**, когда они действительно нужны для задачи.

## Для чего он предназначен

Навык решает одну проблему: LLM-агент "из коробки" ничего не знает про TPG, LOQI2 и внутреннее устройство проектов `its_*`. Информации об этих проектах нет в обучающей выборке, поэтому без подсказки агент либо отказывается работать, либо начинает уверенно выдумывать синтаксис и поведение инструментов.

Навык дает агенту:

- ориентиры по семантике LOQI и TPG - какие бывают узлы, как устроены выражения, где искать точную грамматику;
- знание о деталях поведения и реализации - какой класс отвечает за конкретную стадию сборки графа, как читать трассу рассуждателя, как устроено компилированное XML-представление;
- рабочие процессы для типовых операций - валидация, преобразование между представлениями, запуск рассуждателя, отладка;
- установку "не доверять памяти": по всем вопросам синтаксиса и поведения агент должен сверяться с актуальными исходниками, грамматикой `LoqiGrammar.g4` и опубликованной документацией, а не полагаться на то, что он "помнит".

> [!warning] Навык - для исследования, а не для написания графов
> Навык стоит рассматривать как **исследовательский инструмент**: он помогает разобраться в семантике TPG, объяснить поведение рассуждателя, найти причину ошибки, соотнести трассу с исходным графом, изучить устройство модели предметной области.
>
> Он **не предназначен** для того, чтобы поручать агенту написание графов мыслительных процессов. Граф - это формализация методической модели, и его качество определяется не синтаксической корректностью, а тем, насколько верно он отражает разбираемое умение и типичные ошибки студентов. Сгенерированный агентом граф может успешно проходить валидацию и при этом быть методически бессмысленным.
>
> Разумное разделение труда: граф проектирует и пишет человек, а агент помогает понять, что происходит, и найти ошибки.

## Предварительные требования

Навык рассчитан на артефакты версии `3.0` и новее. Нужные проекты должны быть установлены в локальный Maven-репозиторий:

```bash
mvn clean install
```

в каждом из `its_DomainModel` (`3.0.0-rc.1` и новее), `its_Reasoner` (`3.0.0-rc.1` и новее) и `its_QuestionGen`.

Если jar-файлы CLI не найдены локально, агент, следуя навыку, не станет их выдумывать, а попросит собрать или предоставить нужный артефакт.

## Установка

Навык устанавливается одинаково во всех поддерживающих его клиентах - достаточно склонировать репозиторий в каталог навыков.

### Claude Code

Глобально (для всех проектов):

```bash
git clone https://github.com/CompPrehension/thought-process-graph-skill.git \
  ~/.claude/skills/thought-process-graph
```

Либо только для конкретного проекта - в `.claude/skills/thought-process-graph` внутри репозитория проекта.

Claude Code подхватывает навык автоматически по его описанию, когда в задаче упоминаются TPG, LOQI, `its_DomainModel` и т. п. Явно вызвать его можно командой `/thought-process-graph`.

### Codex

```bash
git clone https://github.com/CompPrehension/thought-process-graph-skill.git \
  ~/.codex/skills/thought-process-graph
```

В Codex навык вызывается явно через `$thought-process-graph`, например:

```text
$thought-process-graph Проверь tpg_main.tpg относительно домена ./domain и объясни ошибки
```

Файл `agents/openai.yaml` в репозитории задает отображаемое имя и подсказку по умолчанию для интерфейса Codex.

### OpenCode

```bash
git clone https://github.com/CompPrehension/thought-process-graph-skill.git \
  ~/.config/opencode/skills/thought-process-graph
```

Для установки в рамках одного проекта используйте `.agents/skills/thought-process-graph`.

> [!tip] Один каталог на несколько клиентов
> Чтобы не держать несколько копий, удобно хранить навыки в общем каталоге (например, `~/.agents/skills/`) и делать символические ссылки на него из каталогов конкретных клиентов:
>
> ```bash
> git clone https://github.com/CompPrehension/thought-process-graph-skill.git \
>   ~/.agents/skills/thought-process-graph
> ln -s ~/.agents/skills/thought-process-graph ~/.claude/skills/thought-process-graph
> ln -s ~/.agents/skills/thought-process-graph ~/.codex/skills/thought-process-graph
> ```

### Обновление

Навык - это обычный git-репозиторий, поэтому обновляется он привычным способом:

```bash
git -C ~/.claude/skills/thought-process-graph pull
```

## Примеры задач

Формулировки, на которых навык действительно полезен:

- "Объясни, почему рассуждатель на этой ситуации уходит в ветку `else`, и покажи, на каком узле расходится трасса";
- "Разбери, что означает вот этот фрагмент LOQI2, и сверься с актуальной грамматикой";
- "Домен не проходит `validate-dsm`, вот вывод - найди причину и скажи, ошибка это в модели или баг инструмента";
- "Сопоставь компилированный XML с исходным `.tpg` и найди, где потерялся переход";
- "Найди в графе все узлы с заданным значением метаданных".

И формулировки, которых лучше избегать:

- "Напиши граф мыслительных процессов для темы X";
- "Придумай недостающие ветки для разбора ошибок студентов".

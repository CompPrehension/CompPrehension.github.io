Дерево может быть описано с помощью нескольких инструментов

## 1. Визуальный

*Читать подробнее: [Визуальный редактор draw.io](<./Способы описания/Визуальный редактор draw.io>)*

Используется [draw.io](https://app.diagrams.net) для визуального построения дерева с помощью специального плагина. Каждое визуальное представление дерева, которое "размечено" этим плагином, может быть экспортировано в модель домена и дерево в формате xml, поддерживаемую рассуждателем

## 2. Расширение DSL LOQI для поддержки описания узлов дерева

*Читать подробнее: [LOQI2](<./Способы описания/LOQI2>)*

Для поддержки возможности описывать дерево, наряду с моделью, привычным для программистов способом, было разработано расширение языка [LOQI](<./../Модель предметной области/Представления данных/LOQI>), который ранее предназначался только для описания модели.

LOQI2 предлагает способ описания древовидной структуры дерева мыслительных процессов и его узлов в стиле императивных языков программирования

## Сериализованное представление и преобразования

Внутренним, "рабочим" представлением дерева остается `xml` - именно в него преобразуются оба описанных выше способа, и именно к нему ближе сама модель данных, используемая рассуждателем во времени выполнения.

Преобразования между представлениями выполняются командами [CLI](../../4.%20Инструменты/CLI.md):

- `domain-cli tree-loqi-to-xml` - из LOQI2 в XML (основной, рабочий сценарий);
- `domain-cli decompile-tree` - из XML обратно в LOQI2. Эта возможность является **экспериментальной** и предназначена для анализа и миграции уже существующих графов.
